# Project provenance

WorkforceLens is Sanif Mujawar's adapted project, based on RetainWise by Muhammad Asim Arshad (repository-local author Ch Asim Arshad), https://github.com/chasimarshad-bot/RetainWise-Employee-Attrition-Insights . The inherited Git history is retained; earlier commits and their authors have not been relabelled.

Reused components include data acquisition and validation, the fictional source and processed v1 dataset, descriptive helpers, dependency pins and container scaffolding. Original documentation, notebooks, tests, planning scripts and QA records are retained as inherited material. They describe RetainWise and do not establish independent student work, current WorkforceLens testing or a WorkforceLens deployment.

The new focus is pooled versus composition-standardised overtime comparisons. New implementation commits use Sanif Mujawar <sanifmujawar@gmail.com>. Sanif must review the methods and provide his own interpretation and reflection before assessment. Dataset and third-party terms remain applicable; see ../data/SOURCE.md. No public open-source licence for the upstream project code is asserted.
